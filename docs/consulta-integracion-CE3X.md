# Consulta preparada sobre la integración de CE³X 3.2

Destinatario propuesto: info@efinovatic.es. No se ha enviado; requiere autorización para contactar con un destinatario nuevo.

**Asunto:** Integración del motor CE³X 3.2: API y ejecución en servidor

Hola:

Estamos desarrollando una aplicación de captura y gestión de expedientes energéticos, con consulta al Catastro, almacenamiento de los datos e intercambio de CEX residenciales 3.2. Queremos estudiar una integración del cálculo oficial y la generación de XML y PDF desde esa aplicación, con resultados contrastados y respetando las condiciones de uso del programa.

¿Podéis indicarnos si existe una API, SDK o modo automatizado admitido para ejecutar el cálculo completo de CE³X 3.2? En particular, necesitaríamos aclarar:

- El protocolo para inicializar y validar el contexto completo del motor, sin sustituir sus comprobaciones.
- Si la integración debe ejecutarse como complemento dentro de CE³X y qué interfaz se admite para intercambiar entradas y resultados.
- Las condiciones aplicables al alojamiento en servidor, al uso concurrente y a la distribución de los componentes necesarios.
- El procedimiento o los casos de referencia recomendados para comparar demanda, consumo, emisiones, calificación y XML.

La consulta no incluye expedientes de clientes ni archivos del programa. En esta fase buscamos información técnica y condiciones de integración; no solicitamos contratar un servicio ni realizar una compra.

Gracias. Un saludo.
